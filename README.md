# ☕ Core Java

> A comprehensive collection of **Core Java** programs covering Java Fundamentals, Object-Oriented Programming (OOP), Collections Framework, JDBC, Multithreading, Exception Handling, File Handling, Data Structures & Algorithms (DSA), and interview-oriented coding problems.

This repository is designed for **students, beginners, and Java developers** who want to build a strong foundation in Java through practical examples and hands-on coding exercises. The programs are organized into well-structured packages, making it easy to learn and revise Core Java concepts.

---

# 📖 About This Repository

The **Core_Java** repository contains numerous Java programs that demonstrate the concepts of Core Java from beginner to intermediate level. It includes examples of Java syntax, OOP concepts, collections, multithreading, file handling, JDBC, algorithms, and mini-projects.

Whether you're preparing for interviews, improving problem-solving skills, or learning Java from scratch, this repository provides a structured learning path with practical implementations.

* Reverse Array

* Duplicate Elements

## 🔹 Collections Framework

**Definition:** The Java Collections Framework provides classes and interfaces to efficiently store, organize, and manipulate groups of objects.

* ArrayList
* LinkedList
* HashSet

* Iterator

* Comparator

## 🔹 Exception Handling

**Definition:** Exception handling allows Java programs to detect, handle, and recover from runtime errors without crashing.

* Try-Catch
* Multiple Catch Blocks
* Finally Block
* Throw & Throws
* Custom Exceptions

## 🔹 Multithreading

**Definition:** Multithreading enables multiple threads to execute simultaneously, improving the performance and responsiveness of applications.

* Thread Class
* Runnable Interface
* Thread Lifecycle
* Synchronization Basics

**Definition:** JDBC is a Java API that enables Java applications to connect with relational databases and perform database operations.

* Database Connection
* CRUD Operations

* PreparedStatement
* ResultSet Handling

## Clone the Repository

```bash

```

```bash

```

* IntelliJ IDEA


## Run

